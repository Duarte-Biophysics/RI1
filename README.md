# RL1-Comparar Herois
um código onde compara heróis da **Marvel** entre si e dita um vencedor de acordo com os atributos de cada um
são eles:
- Thor
- Homem Aranha
- Homem de Ferro
- Homem Formiga
- Thanos

## Como funciona?
primeiro crio os heróis e adicionando os atributos a eles como "força", "velocidade" etc, depois organizo essas informações em uma função e crio uma lista para guardar os personagens, faço 2 loops um dentro do outro e crio as variáveis "heroi1" e "heroi2" que resgatam as informações de heróis diferentes e depois são comparados em cada atributo, imprimindo no final o resultado.
